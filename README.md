## 🛠️ Overview

**Sandro Ferro — Master Ironworks** is a premium, editorial-style artisan website created for a Dublin-based ironworks and metal sculpture studio.

The experience combines:

- Luxury editorial web design
- Artisan portfolio presentation
- Product catalogue
- Shopping cart interaction
- Commission enquiries
- Gallery and project showcase
- Interactive animations
- Responsive mobile experience
- Client testimonials
- Administrative product and gallery management

The website presents the atelier as a high-end destination for **hand-forged iron sculptures, blades, shields, architectural installations and bespoke commissions**.

The site identifies Sandro Ferro as a Dublin master ironworks studio and presents the brand as established in 2005. :contentReference[oaicite:1]{index=1}
